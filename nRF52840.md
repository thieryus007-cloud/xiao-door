Mise en œuvre du XIAO nRF52840 Sense avec Home Assistant

Introduction

Ce document détaille deux approches pour intégrer le Seeed Studio XIAO nRF52840 Sense (et sa version Sense Plus) avec Home Assistant via BLE et le protocole BTHome, en exploitant les capteurs embarqués (notamment l'IMU). Les deux solutions sont matures et documentées.

· Option 1 : BTHome avec CircuitPython – Solution légère et flexible, idéale pour les capteurs IMU et les projets rapides.
· Option 2 : Seeed HA Discovery – Solution officielle de Seeed Studio, basée sur Arduino, offrant une communication bidirectionnelle et une intégration poussée.

---

Option 1 : BTHome avec CircuitPython (recommandée pour l'IMU)

Cette option utilise le projet open-source "BTHome Inertial Sensor in CircuitPython" de Koen Vervloesem. Elle est spécifiquement conçue pour détecter les mouvements du XIAO nRF52840 Sense et les publier via BTHome.

1.1 Prérequis matériels

· 1 × Seeed Studio XIAO nRF52840 Sense (ou Sense Plus)
· 1 × câble USB-C pour la programmation

1.2 Installation du firmware CircuitPython

1. Téléchargez la dernière version de CircuitPython pour le XIAO nRF52840 Sense depuis circuitpython.org.
2. Connectez la carte à votre ordinateur et appuyez deux fois sur le bouton RST pour entrer en mode bootloader. Un disque nommé XIAO-SENSE apparaît.
3. Glissez-déposez le fichier .uf2 téléchargé sur ce disque. La carte redémarre et un nouveau disque CIRCUITPY apparaît.

1.3 Installation des librairies

1. Téléchargez le bundle de librairies CircuitPython 8.x depuis circuitpython.org/libraries.
2. Décompressez l'archive et copiez les dossiers suivants dans le dossier lib du disque CIRCUITPY :
   · adafruit_bus_device
   · adafruit_lsm6ds (pour l'IMU)
   · adafruit_register

1.4 Téléchargement du code

1. Récupérez le fichier code.py depuis le dépôt GitHub.
2. Copiez-le à la racine du disque CIRCUITPY.
3. La carte diffuse désormais automatiquement les données de mouvement via BTHome.

1.5 Personnalisation avancée

Vous pouvez modifier les constantes en tête du fichier code.py :

```python
DEVICE_NAME = "MonCapteurIMU"   # Nom affiché dans Home Assistant
INTERVAL = 0.1                  # Intervalle entre les publicités BLE (en secondes)
SENSITIVITY = 0.01              # Seuil de sensibilité du détecteur de mouvement
```

1.6 Configuration de Home Assistant

1. Assurez-vous que votre passerelle Bluetooth est reconnue par Home Assistant.
2. Allez dans Paramètres → Périphériques et services → Intégrations.
3. Ajoutez l'intégration Bluetooth si elle n'est pas déjà présente.
4. Ajoutez l'intégration BTHome. Votre capteur devrait être automatiquement découvert.

Option 2 : Seeed HA Discovery (solution officielle)

Seeed HA Discovery est une solution complète fournie par Seeed Studio pour connecter facilement des périphériques ESP32/nRF52840 à Home Assistant. Elle utilise le protocole BTHome v2 et supporte la communication bidirectionnelle via GATT.

2.1 Prérequis matériels

· 1 × Seeed Studio XIAO nRF52840 Sense (ou Sense Plus)
· 1 × câble USB-C pour la programmation

2.2 Installation de l'intégration Home Assistant

Méthode A : Via HACS (recommandée)

1. Ouvrez HACS → Integrations.
2. Cliquez sur ⋮ en haut à droite → Custom repositories.
3. Ajoutez l'URL : https://github.com/limengdu/Seeed-Homeassistant-Discovery
4. Sélectionnez la catégorie Integration.
5. Recherchez Seeed HA Discovery et installez.
6. Redémarrez Home Assistant.

Méthode B : Installation manuelle

Copiez le dossier custom_components/seeed_ha_discovery dans le répertoire config/custom_components/ de Home Assistant, puis redémarrez.

2.3 Installation de la bibliothèque Arduino

1. Téléchargez la bibliothèque BLE depuis le dépôt : arduino/SeeedHADiscoveryBLE.
2. Copiez le dossier SeeedHADiscoveryBLE dans Documents/Arduino/libraries/.

Note importante : Pour la carte XIAO nRF52840, la bibliothèque ArduinoBLE est intégrée au core Seeed mbed. Aucune installation supplémentaire n'est nécessaire.

2.4 Programmation de la carte

Voici un exemple de code pour publier la température, l'humidité et le niveau de batterie :

```cpp
#include <SeeedHADiscoveryBLE.h>

SeeedHADiscoveryBLE ble;
SeeedBLESensor* tempSensor;
SeeedBLESensor* humiditySensor;
SeeedBLESensor* batterySensor;

void setup() {
  Serial.begin(115200);
  ble.enableDebug(true);
  
  if (!ble.begin("XIAO Temperature Sensor")) {
    Serial.println("BLE initialization failed!");
    while (1) delay(1000);
  }
  
  // Utilisation des types de capteurs standards BTHome
  tempSensor = ble.addTemperature();
  humiditySensor = ble.addHumidity();
  batterySensor = ble.addBattery();
}

void loop() {
  tempSensor->setValue(25.5);    // Température 25.5°C
  humiditySensor->setValue(55.0); // Humidité 55%
  batterySensor->setValue(100);   // Batterie 100%
  
  ble.advertise();  // Diffusion BLE
  delay(10000);     // BLE adapté aux mises à jour peu fréquentes
}
```

2.5 Communication bidirectionnelle (exemple avec LED)

Seeed HA Discovery permet également de recevoir des commandes depuis Home Assistant :

```cpp
#include <SeeedHADiscoveryBLE.h>

SeeedHADiscoveryBLE ble;
SeeedBLESwitch* ledSwitch;

void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  ble.enableDebug(true);
  
  // Second paramètre à true pour activer le serveur GATT
  if (!ble.begin("XIAO LED Controller", true)) {
    Serial.println("BLE initialization failed!");
    while (1) delay(1000);
  }
  
  ledSwitch = ble.addSwitch("led", "Onboard LED");
  // Le callback est exécuté lors de la réception d'une commande HA
}

void loop() {
  ble.handle();  // Gère les communications GATT entrantes
}
```

2.6 Flashage sans IDE (optionnel)

Seeed propose un flasheur web pour programmer la carte directement depuis le navigateur, sans installer Arduino IDE. Rendez-vous sur Seeed HA Discovery Web Flasher.
